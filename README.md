# Создать .md

Небольшая программа для macOS: по клику создаёт пустой файл `Новый документ.md` в активном окне Finder и сразу его выделяет.

Готового установщика нет. Программа собирается на вашем Маке из исходников. Так она подписывается локально и не упирается в Gatekeeper.

## Зачем

В Finder нет пункта «создать текстовый файл». Эта программа закрывает именно эту дыру для Markdown: один клик — новый `.md` в той папке, которая сейчас открыта.

## Что нужно

- macOS 13 или новее
- [Command Line Tools](https://developer.apple.com/xcode/resources/): `xcode-select --install`

Xcode целиком не нужен.

## Установка

```bash
git clone https://github.com/HanenVit/create-markdown.git
cd create-markdown
chmod +x scripts/install.sh scripts/uninstall.sh
./scripts/install.sh
```

Скрипт собирает программу, кладёт её в `~/Applications/Create Markdown.app` и добавляет службу Finder «Создать .md». Dock на секунду перезапустится — так подхватывается иконка.

Перетащите `Create Markdown` из своей папки «Программы» в Dock.

На Маке две папки «Программы». Общая — `/Applications`. Своя — домашняя, `~/Applications`. Программа ставится во вторую.

## Как пользоваться

**Ярлык в Dock.** Откройте нужную папку в Finder и нажмите ярлык. Файл появится в переднем окне Finder, окно само переключится на него.

Если ни одного окна Finder нет, файл создаётся на рабочем столе.

**Служба.** Правый клик по файлу или папке → «Службы» или «Быстрые действия» → «Создать .md». Файл появится в этой папке, либо рядом с выбранным файлом.

По пустому месту службы может не быть. Тогда кликните по любому файлу в папке или используйте ярлык в Dock.

Если имя `Новый документ.md` уже занято, программа создаст `Новый документ 2.md`, затем `3` и так далее.

## Первый запуск

macOS спросит, можно ли программе управлять Finder. Нажмите «Разрешить». Без этого она не узнает, какая папка открыта.

Если окно запроса уже закрыли, разрешение включается здесь: «Системные настройки» → «Конфиденциальность и безопасность» → «Автоматизация» → Create Markdown → Finder.

## Удаление

Скрипт не устанавливается в систему и не лежит в общей папке. Он остаётся только внутри скачанного репозитория, рядом с `install.sh`:

```text
create-markdown/scripts/uninstall.sh
```

`./` значит «в той папке, где вы сейчас стоите». Из другой папки эта команда просто не найдётся и ничего не запустит. Чужой `uninstall.sh` она тоже не подменит: оболочка не ищет скрипт по всему диску.

```bash
cd create-markdown
./scripts/uninstall.sh
```

`create-markdown` здесь — папка, куда вы клонировали репозиторий. Если она называется иначе или лежит не в текущем каталоге, сначала перейдите именно в неё.

Скрипт удаляет только два своих пути: `~/Applications/Create Markdown.app` и службу `~/Library/Services/Создать .md.workflow`. Файлы, которые вы уже создали, остаются на месте.

## Как это устроено

Программа не висит в памяти. По клику она спрашивает у Finder переднее окно, создаёт файл и сразу завершается.

Служба делает то же самое, только папку берёт из того, по чему вы кликнули.

Отдельного расширения Finder нет: оно постоянно занимало память и не работало в папках iCloud. Служба и ярлык этой проблемы не имеют.
